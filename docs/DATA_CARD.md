# Data card: TBV task suite

Status: skeleton. The suite currently holds 5 example tasks (suite/specs); the full suite is not written.

- What it is: a small, custom Python (pytest) task suite with hidden tests as the scoring oracle.
- How it was made: tasks are written as compact specs by an AI assistant (Claude, not the models under test),
  expanded by code, and validated in the sandbox. Tasks were drafted with AI assistance, then checked automatically
  (hidden tests fail on seed, pass on reference, no leakage into repo/, deterministic) and
  hand-reviewed on a sample. Generation prompts are saved in config/prompts/.
- What that implies: tasks may share stylistic artifacts of the drafting model; the suite is
  small; difficulty was calibrated on a pilot; it is not a replacement for public benchmarks and
  no task was copied from one.
- Counts per type, difficulty and split: (generated by `tbv suite validate`, do not type by hand)
- Known limitations: (fill in after manual review)
- Data handling: agent prompts, tool results and final messages are sent to Google's Gemini API on the
  free tier, where content may be used to improve Google's products. Tasks are synthetic and hidden
  tests are never sent to the agent. Do not reuse this suite as a clean benchmark if that matters.
- Hidden tests are published with the suite after the experiment; any later use should treat them as
  contaminated.
