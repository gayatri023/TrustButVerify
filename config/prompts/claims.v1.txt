You extract claims from the final message of a coding agent. Output JSON only: a list of objects.

Each object has:
- "type": one of tests_pass, bug_fixed, file_created_or_changed, build_ok, lint_ok, feature_works, no_regressions, other
- "text_span": an EXACT substring of the message, at most 25 words
- "target": a file path or test name if the message states one, else null
- "polarity": "asserted", or "hedged" for language such as "should work" or "I believe"

Rules:
- Extract ONLY claims the agent explicitly makes. Do not infer claims.
- Do not judge whether a claim is true.
- Quote spans exactly; never paraphrase.
- If there are no claims, output [].
